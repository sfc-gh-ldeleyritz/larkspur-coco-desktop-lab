# CoCo Desktop hands-on lab: Larkspur Group

> **Note:** Larkspur Group is a fictional company. All data and documents are synthetic and for educational purposes only.

A 90-minute hands-on lab in CoCo Desktop for the Larkspur Group leadership team, using Larkspur's data and documents. It covers a business question, a document review, a process diagram, a meeting fact-check, a slide deck, an automated follow-up and a governance check on model usage and data access. Each attendee leaves with a shared report, a PowerPoint deck, a skill and an automation.

Adapted from [CoCo Desktop: I Downloaded CoCo Desktop... Now What?](https://github.com/sfc-gh-cadkins/HandsOnLabs/tree/main/3-CoCo-Desktop) by Caleb Alexander (Apache 2.0).

## Get the lab

In CoCo Desktop, start a **New session** and send:

> Download https://github.com/sfc-gh-ldeleyritz/larkspur-coco-desktop-lab/archive/refs/heads/main.zip, unzip it into my Documents folder, and rename the folder to `larkspur-coco-desktop-lab`. Then list what's inside.

Read what CoCo is about to do before you click **Allow**. Then click the add-project icon next to **Projects**, choose **Open Folder**, and select `larkspur-coco-desktop-lab`. This is your Larkspur project.

The company data is already in Snowflake. You don't need to load anything.

## Set how CoCo writes

In CoCo Desktop, open **Customize > Personalization > Custom instructions**, paste this, and click **Save**. It applies in every project, starting with your next new session.

```
## How to write responses
- Write like a colleague talking, not a report. Plain words, short sentences, UK English.
- Lead with the answer in one or two sentences, then the evidence.
- Use bullets only for three or more parallel items. No headers in short answers.
- Don't open with "Great question" or "Certainly." Don't close with "I hope this helps."
- Don't use dashes as punctuation, or filler words like delve, leverage, robust, seamless, crucial.
- Say what you checked and what you're guessing. If you don't know, say so.
- End with one clear next step or one question, not a menu of options.
```

## After the lab

On your own work:
- Create a folder for each piece of work, put the documents in it, and open it as a project.
- Ask CoCo to summarise, compare or rewrite a document before your next meeting.
- Turn a document into a deck with `/larkspur-deck` before a committee meeting.
- Save anything you do twice as a skill.

## Clean up

When you're done:
- **Automations:** delete any you created, from **Automations** in the sidebar.
- **The lab folder:** delete `larkspur-coco-desktop-lab` from Documents if you no longer need it.
