# CoCo Desktop quickstart

Follow these steps to run the lab. Larkspur Group is fictional; all data is synthetic.

## Before you start
You need CoCo Desktop installed and signed in to your Snowflake account. Your workshop facilitator has already set up your access and the company data.

If something doesn't work, check [Troubleshooting](TROUBLESHOOTING.md).

## Step 1: Check your connection
Open CoCo Desktop and check the connection menu at the top: you should see the workshop connection your facilitator set up for you.

## Step 2: Set up the chat box
1. **Approvals:** leave it on **Default Approvals**, so CoCo asks before it runs anything or edits files.
2. **Mode:** leave it on **Agent**.
3. **Model:** leave it on **Auto**.

## Step 3: Get the lab
1. Start a new session. A **session** is one conversation with one goal.
2. Send the prompt from [Get the lab](README.md#get-the-lab).
3. When an approval card appears, read it before you click **Allow**.
4. Open the `larkspur-coco-desktop-lab` folder as a project. A **project** is a folder; CoCo keeps your sessions and context per project.

## Step 4: Check what CoCo can see
Start a new session in the Larkspur project and send:
> What company data can you see for Larkspur, and what kinds of questions could I ask it?

## Step 5: Follow the workshop
Open [WORKSHOP.md](WORKSHOP.md) and work through the steps with the group. To attach a document, type `@` in the chat box and pick the file. Start a **new session** for each step unless the step says otherwise.

## Step 6: Customise CoCo
Open **Customize** to set:
- **Custom instructions:** short standing preferences, loaded into every conversation.
- **Memory:** notes CoCo keeps between sessions.
- **Skills:** saved tasks you run with `/`.
- **Connectors (MCP):** link other tools, like Draw.io.

## Habits to keep
- Tell CoCo what you want and whether it may change anything.
- Read every approval before you allow it.
- Check one number yourself before you share an answer.
- When CoCo gets something wrong, save a rule once instead of correcting it every time.
